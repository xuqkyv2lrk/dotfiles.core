# Ghostty Cheatsheet

No custom keybinds are set in `config` — everything below is Ghostty's
built-in default on macOS (`super` = `Cmd`). Pulled straight from
`ghostty +list-keybinds --default`, so it stays accurate across upgrades;
re-run that command if this ever looks stale.

## Windows & Tabs

| Key | Action |
|-----|--------|
| `Cmd-N` | New window |
| `Cmd-T` | New tab |
| `Cmd-W` | Close current surface |
| `Cmd-Shift-W` | Close window |
| `Cmd-Alt-W` | Close current tab |
| `Cmd-Alt-Shift-W` | Close all windows |
| `Cmd-1`-`Cmd-8` | Go to tab N |
| `Cmd-9` | Go to last tab |
| `Cmd-Shift-[` / `Cmd-Shift-]` | Previous / next tab |
| `Ctrl-Tab` / `Ctrl-Shift-Tab` | Next / previous tab |

## Splits

| Key | Action |
|-----|--------|
| `Cmd-D` | New split right |
| `Cmd-Shift-D` | New split down |
| `Cmd-[` / `Cmd-]` | Go to previous / next split |
| `Cmd-Alt-Left/Right/Up/Down` | Go to split in that direction |
| `Cmd-Ctrl-Left/Right/Up/Down` | Resize split in that direction |
| `Cmd-Ctrl-=` | Equalize all splits |
| `Cmd-Shift-Enter` | Toggle split zoom |

## Search & Selection

| Key | Action |
|-----|--------|
| `Cmd-F` | Start search |
| `Cmd-Shift-F` | End search |
| `Cmd-E` | Search current selection |
| `Cmd-G` / `Cmd-Shift-G` | Next / previous search match |
| `Cmd-A` | Select all |
| `Shift-Arrow` | Adjust selection |
| `Cmd-C` / `Cmd-V` | Copy / paste |
| `Cmd-Shift-V` | Paste from selection |

## Scrolling & Prompt Navigation

| Key | Action |
|-----|--------|
| `Cmd-Home` / `Cmd-End` | Scroll to top / bottom |
| `Cmd-PageUp` / `Cmd-PageDown` | Scroll page up / down |
| `Cmd-Up` / `Cmd-Down` | Jump to previous / next prompt |
| `Cmd-J` | Scroll to selection |

## Misc

| Key | Action |
|-----|--------|
| `Cmd-Enter` | Toggle fullscreen |
| `Cmd-Ctrl-F` | Toggle fullscreen (alt bind) |
| `Cmd-K` | Clear screen |
| `Cmd-Z` / `Cmd-Shift-Z` | Undo / redo |
| `Cmd-=` / `Cmd--` / `Cmd-0` | Increase / decrease / reset font size |
| `Cmd-Shift-P` | Command palette |
| `Cmd-Alt-I` | Toggle inspector |
| `Cmd-,` | Open config |
| `Cmd-Shift-,` | Reload config |
| `Cmd-Q` | Quit |
